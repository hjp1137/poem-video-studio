## 2. 服务化步骤

1. **填写 unit**:按 `agent/systemd/minimax-h3.service.example` 与 `comfyui.service.example` 创建 `/etc/systemd/system/minimax-h3.service`、`/etc/systemd/system/comfyui.service`,ExecStart 使用上表采集的**原样命令**(绝对路径),不重新设计推理参数。
2. **安装 Agent 与注册表**:见 `agent/README.md`;`/etc/poem-video-agent/services.yaml` 中 health.url 用上表实测的 H3 Ready 判定接口(不触发推理)与 ComfyUI `http://127.0.0.1:8188/system_stats`。
3. **sudoers 放行**:unit 名与 `agent/sudoers/poem-video-agent` 枚举一致;新增受管服务必须同步改 sudoers(防 Web 扩权)。
4. **停止原手工进程**(tmux 内 Ctrl-C 或原停止方式),确认显存释放:`nvidia-smi`。
5. `sudo systemctl daemon-reload && sudo systemctl start minimax-h3`,观察 `journalctl -u minimax-h3 -f` 至模型加载完成。
6. **迁移前后对比**(任务05 §4 硬性要求):
   - GPU 使用(`nvidia-smi` 各卡显存/利用率一致);
   - 端口(`ss -lntp` 一致);
   - 模型加载(vLLM 日志无新增告警);
   - H3 生成结果(用 PoemVideo Studio 提交同一首诗的批量任务对比输出)。
7. ComfyUI 重复 4~6 步。
8. 开机自启策略(任务05 §19):`poem-video-agent`、`poem-video-api/web` 建议 enabled;H3/ComfyUI 是否开机自启由用户决定——服务器平时还跑 Ollama 等其他任务时,建议不 enable,经「准备视频生成环境」按需启动。

## 3. Profile 配置

`server/profiles.yaml`(studio 侧,挂载到容器 `/app/server`):

- `gpu_power.watts`:按真实 4090 功耗策略确认(默认 280);
- `stop_services`:**必须依据真实 GPU 分配确认**后配置,不能为"释放显存"默认停掉所有服务;
- `readiness.*_timeout_seconds`:按实测 H3 加载耗时设置(默认 300/120 秒)。

## 4. 日志位置

| 层 | 位置 |
|---|---|
| PoemVideo 业务/审计 | `DATA_ROOT/logs/` + `server_operations` 表(页面「服务器 → 操作日志」) |
| Agent | `journalctl -u poem-video-agent` |
| 开机功耗应用 | `journalctl -u poem-video-gpu-power` |
| MiniMax H3 | `journalctl -u minimax-h3` |
| ComfyUI | `journalctl -u comfyui` |

## 5. 故障排查

| 现象 | 排查 |
|---|---|
| 页面服务状态 unknown | Agent 侧 `systemctl show <unit>`;unit 未安装/名字不符 |
| H3 Running 但 Unhealthy | `curl <health.url>`;端口/路径与核查清单不一致 |
| prepare 失败在 wait_h3 | `journalctl -u minimax-h3 -n 200`;readiness 超时过短 |
| prepare 失败在 apply_power | `sudo -u poemagent sudo -n nvidia-smi -i 0 -pl 280`;sudoers |
| 停止按钮被阻断 | 设计行为:有生成任务或队列非空时需二次确认(force) |

## 6. 临时回退到手工启动

```bash
sudo systemctl disable --now minimax-h3 comfyui   # 停用服务化
# 按迁移前核查清单记录的原命令,在 tmux 中手工启动 H3 / ComfyUI
```

PoemVideo Studio 批量生成只依赖 ComfyUI HTTP 可达,不依赖 systemd 化;回退后页面仍可正常提交生成(服务器控制中心状态页将显示服务 unknown,属预期)。
