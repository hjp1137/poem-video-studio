# 2026-09-28 批量下载、多版本输出与场景参数管理 计划

## 需求(本轮新增三项,连同上轮收尾)

1. 批次详情场景任务表加复选框,勾选后批量下载已生成视频(zip 打包);
2. 重试多次产生的多个视频都保留可下载(多版本输出历史);
3. 每个场景下方增加参数管理区(width/height/fps/num_frames/prompt/negative_prompt/speech),可修改并应用(保存后重试即按新参数二次创作)。

## 方案

### 后端

1. **多版本输出**:新表 `task_outputs`(id, task_id, batch_id, output_path, output_filename, subfolder, type, created_at);`reconcile_task` 完成时追加记录(旧 VideoTask.output_path 保留为最新值兼容);`TaskOut` 增加 `outputs` 列表(无记录但 output_path 有值时构造兼容项);
2. **参数管理**:`PUT /api/tasks/{id}/params` 更新 width/height/fps/num_frames/prompt/negative_prompt/speech(整数范围校验复用 batch_parser 的 GLOBAL_INT_RANGES 语义,本地定义);
3. **批量下载**:`GET /api/batches/{id}/download?task_ids=a,b,c` 流式返回 zip(文件名 `{scene_key}_{序号}_{文件名}`;无已完成输出时 400);
4. **对账周期可配**:settings 加 `reconcile_interval_seconds`(默认 30,E2E 调小加速),monitor_loop 使用;
5. mock_agent_app:加 histories 状态+`/_e2e/control` 支持设置 prompt 完成记录(带 MP4 输出),E2E 可驱动「生成→重试→再生成」多版本闭环;mock fetch /view 返回假 MP4 字节。

### 前端(BatchDetailView)

1. 表格加 selection 列(仅 completed 行可选),工具栏「下载选中 (N)」→ window 打开下载端点;
2. 输出列:多版本链接(版本 n + 预览 + 下载),下载用 video_url+download 属性;
3. expand 展开行:7 个参数的表单(数字输入框/多行文本),「保存参数」(PUT 后刷新)与「保存并重新生成」(保存→对 pending/failed 直接重试)。

### E2E/测试

- pytest:outputs 追加(两次完成两条记录)、params 更新校验、zip 下载内容;
- E2E:更新 batch-create(勾选/下载按钮存在)+新用例「多版本与参数管理」(创建→自动入队→mock 设完成→等对账 completed→重试→再设完成→两个版本→勾选批量下载断言 zip→展开改参数保存断言);
- 修复上轮 server-services 残留(清理 .e2e-data 与复用进程)。
