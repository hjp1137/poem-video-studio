# 2026-09-28 创建自动入队与队列操作按钮 计划

## 需求

1. 创建批次后自动提交进入生成队列(前端串联:创建成功→调 submit→跳详情);
2. 批次列表每行新增「提交队列/移除队列」按钮(不加二次确认):
   - 提交队列 = 已有 POST /api/batches/{id}/submit;
   - 移除队列 = 新增 POST /api/batches/{id}/cancel-queued:把仍在 ComfyUI pending 队列的本批次任务删除(DELETE /queue {delete:[prompt_id]}),本地 queued 任务回 pending 并清 prompt_id;running/completed/failed 不动;随后刷新批次状态;
   - 按钮显示:batch.status ∈ {queued,running,submitting} → 「移除队列」,否则 → 「提交队列」;
3. 批次详情「重试」按钮去掉二次确认弹窗,点击直接重试。

## 改动

### 后端
- comfyui_client:新增 `delete_queue_items(prompt_ids)`(DELETE /queue,body {"delete":[...]});
- task_tracker:新增 `cancel_queued_batch(db, batch_id)`(仅 queued 状态任务;ComfyUI 队列中已不存在的也一并回 pending);submit/cancel 后 `_refresh_batch_status` 已有;
- api/batches:新增 `POST /{batch_id}/cancel-queued` 路由,返回 {cancelled, remaining_running};
- mock_agent_app(E2E):补 POST /upload/image、POST /prompt(自动提交路径需要)、DELETE /queue。

### 前端
- BatchCreateView:doCreate 成功后自动 submitBatch(id)(失败不阻断跳转,提示可手动提交);
- BatchListView:操作列加「提交队列/移除队列」按钮(按行状态切换,禁用条件:无待提交任务时「提交队列」禁用);
- BatchDetailView:重试按钮移除 el-popconfirm 包裹,直接 doRetry。

### E2E
- batch-create:创建后断言任务自动 queued(依赖 mock /prompt);
- 新增 batch-list 队列按钮用例(提交→移除→任务回 pending);
- 批次详情重试直接执行断言(可选,并入 list 用例)。
