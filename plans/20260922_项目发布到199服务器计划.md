## 2. 发布范围

1. **代码同步**:rsync 工作区 → `/opt/poem-video-studio`(排除 .git、node_modules、.venv、dist、data、.e2e-data、__pycache__、test-results、.pytest_cache)。
2. **PoemVideo Studio(API+Web)**:`docker compose build && up -d`,宿主端口 API 8000 / Web 8080(均空闲);命名卷 poem-data 新建,不触碰既有容器与卷;`.env` 中 ComfyUI 指向 `host.docker.internal:8188`(未运行,健康检查将如实显示异常)、Agent 指向 `host.docker.internal:8300`。
3. **poem-video-agent(宿主机)**:python3.12 venv + requirements;systemd 常驻,**按服务器 root 运行现状适配**(User=root、AGENT_USE_SUDO=0,无需 sudoers;监听 127.0.0.1:8300);配置目录 `/etc/poem-video-agent`:gpu-power.json(enabled=false,不擅自开机改功耗,由用户在页面开启)、services.yaml(**空注册表**——H3/ComfyUI 尚未 systemd 服务化,登记不存在的 unit 会显示假状态;服务化属任务05 真实验收,不在本次发布范围)。
4. **验证**:Agent /v1/health 与 /v1/gpus 返回 4 卡;API /api/system/health;Web 页面;GPU 页经 Agent 显示真实 4×4090(450W);既有容器全部不受影响(发布前后 docker ps 对比);SSH 隧道 + Playwright 截图留证。

## 3. 明确不做

- 不停止/重启任何既有容器与 vLLM/Ollama 进程;
- 不修改 GPU 功耗(450W 保持;页面可由用户自行设置);
- 不执行 H3/ComfyUI systemd 服务化迁移(任务05 §2 前置核查与 §4~5 迁移,单独执行);
- 不在服务器上写测试数据、不清任何卷。

## 4. 回滚

`docker compose down`(卷保留);`systemctl disable --now poem-video-agent`;删除 `/opt/poem-video-studio` 与 `/etc/poem-video-agent` 即可完全移除,不影响服务器其他业务。
