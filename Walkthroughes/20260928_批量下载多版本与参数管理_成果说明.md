# 2026-09-28 批量下载、多版本输出与场景参数管理 成果说明

## 实现内容

1. **复选框批量下载**:批次详情场景任务表新增复选框(仅有输出的任务可选),工具栏「下载选中 (N)」一键打包 zip 下载(文件名 `批次名/场景序号_key_v版本.mp4`);新增 `GET /api/batches/{id}/download?task_ids=`;
2. **多版本输出**:新表 `task_outputs` 记录每次生成的输出;`download_output` 落盘命名递增(`00_cover.mp4`/`00_cover_v2.mp4`…,修复了重试覆盖旧版本的问题);重试多次后每个版本都可独立下载(操作列 v1/v2 链接);旧数据无记录时用最新输出兜底;

4. 配套:HTTP 对账周期可配(`RECONCILE_INTERVAL_SECONDS`,默认 30s);E2E mock 支持 set_history 注入完成记录与假 MP4 字节。
