## 一、实现内容

### 1. 输出管理

- 完成任务的视频由 `/view` 下载复制到 `outputs/{batch_id}/{scene_order:02d}_{scene_key}.mp4`,数据库登记 output_path/filename/subfolder/type,不做模糊 glob 关联。

### 2. 下载 API(`backend/app/api/tasks.py`)

- `GET /api/tasks/{id}/video`:浏览器内联预览(video/mp4);
- `GET /api/tasks/{id}/download`:attachment,文件名 `诗名_序号_诗句简名.mp4`(非法字符过滤);
- 仅允许访问数据库登记的 outputs/ 下文件,路径 resolve 防目录穿越,文件不存在返回明确 404。

### 3. 系统运行状态

- `GET /api/system/health`、`/api/system/status`:API / SQLite / Data Directory / Workflow Template / ComfyUI HTTP / ComfyUI Queue 六项;健康检查不触发推理;
- 前端批次列表页常驻系统状态区,任务详情页显示 ComfyUI 连接状态。

### 4. 服务启动与恢复

- 启动时 `startup_reconcile`:queued/running 任务按 prompt_id 查 history,完成补记 completed、失败补记 failed、无法确认标记 recover_pending;SQLite 数据与已完成输出重启不丢。

### 5. Docker 部署

- `docker-compose.yml`:poem-video-api(python:3.11-slim + uvicorn)+ poem-video-web(nginx 托管前端构建产物并反向代理 /api 含 WebSocket);`restart: unless-stopped`;数据命名卷 `/data/poem-video-studio`;`extra_hosts: host-gateway`;ComfyUI 地址走 `.env` 不硬编码;不打包 MiniMax H3/vLLM/ComfyUI;
- `.env.example` 覆盖任务书 §7 全部键;`README.md` 含任务书 §10 要求的 12 项内容。
