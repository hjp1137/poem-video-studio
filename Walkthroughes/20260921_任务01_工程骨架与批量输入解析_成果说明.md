## 一、实现内容

### 1. 工程骨架

```text
backend/   FastAPI + SQLAlchemy + SQLite(Python 3.10 本机运行兼容,Docker 用 3.11)
frontend/  Vue 3 + Vite + TypeScript + Element Plus
workflows/ 示例模板 minimax_h3_poem_v1.example.json + workflow-map.example.yaml
docker/  docker-compose.yml  .env.example  .gitignore  .dockerignore  README.md
```

后端模块:`app/api(uploads/batches/tasks/system/ws)`、`app/core(config/database)`、`app/models(batch/task/upload)`、`app/schemas`、`app/services(batch_parser/upload_service 等)`。

### 2. 批量文本解析器(batch_parser)

- 首个非空行必须为 `POEM_VIDEO_BATCH_V1`,否则报错;
- 头部 title/dynasty/author;`[GLOBAL]` 可缺省,width/height/fps/num_frames 非法(非整数/越界)报错,negative_prompt 多行保留;
- `[SCENE:cover]` 可选、`[SCENE:1..N]` 数量不限,prompt/speech 多行保留、原文不改写;
- scene key 重复报错;编号断裂给明确警告(指明缺失编号);缺 prompt/speech 指明具体 scene;
- 场景顺序固定 cover → 1 → 2 → …;输出 `{metadata, global, scenes[], warnings[], errors[], ok}`。

### 3. 图片上传与绑定

- `POST /api/uploads`:PNG/JPG/JPEG/WEBP,单文件 20MB 上限(配置项),uuid 前缀防覆盖;
- 文件名猜测场景 key(cover.png→cover、01.png/1.png→1),前端可手工调整顺序、标记 cover、重新绑定,不依赖文件名;
- 创建批次时图片复制到 `uploads/{batch_id}/{scene_order:02d}_{scene_key}.png` 落库。

### 4. 批次创建

- `POST /api/batches` 服务端**重新解析校验**(文本为唯一事实来源),每个场景必须已绑定图片,否则 422 并指明未绑定的场景;
- 创建后数据库生成 1 个 Batch(status=parsed)+ N 个 VideoTask(status=pending),刷新页面数据仍在。

### 5. 前端「新建批量任务」页

基本信息表单、拖拽多图上传(卡片含缩略图/识别标签/排序/移除)、批量文本框、解析任务/清空按钮、场景预览卡片(scene key/缩略图/speech/prompt 摘要/宽高·fps·帧数)、顶栏「共 N 个场景 · 已绑定 M 张图片 · 可否提交」、解析错误逐条展示(带行号)、创建批次按钮(未满足条件时禁用)。

另含批次列表页(含六项系统运行状态)与批次详情页(见任务02说明)。
