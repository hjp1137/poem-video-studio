# 2026-09-21 任务01：PoemVideo Studio V1.0 工程骨架、批量输入与解析

## 1. 任务目标

完成 PoemVideo Studio V1.0 的基础工程骨架，并实现“整首诗一次输入”的最小闭环前半段：

> 一次上传封面 + N 张诗句场景图 → 一次粘贴批量 Prompt → 自动解析为多个场景任务 → 在页面正确预览。

本任务暂不调用 ComfyUI，不执行实际视频生成。

## 4. 批量任务格式

必须支持：

```text
POEM_VIDEO_BATCH_V1

title: 宿建德江
dynasty: 唐
author: 孟浩然

[GLOBAL]
width: 768
height: 1024
fps: 24
num_frames: 121

negative_prompt:
统一反向提示词……

[SCENE:cover]
speech: 宿建德江，唐，孟浩然。
prompt:
封面 Prompt……

[SCENE:1]
speech: 移舟，泊烟渚。
prompt:
第一句 Prompt……

[SCENE:2]
speech: 日暮，客愁新。
prompt:
第二句 Prompt……
```

要求：

- [GLOBAL] 可缺省，缺省时采用默认参数。
- [SCENE:cover] 可选。
- [SCENE:1..N] 数量不设死为 4。
- prompt 支持多行。
- negative_prompt 支持多行。
- speech 保留原文本，不做自动改写。
- 场景顺序按 cover → 1 → 2 → ... 排列。
- 重复 scene key 必须报错。
- scene 编号断裂必须给出明确提示。
- 缺少 prompt / speech 时明确指出对应 scene。

## 5. 默认生成参数

配置默认值：

```text

num_frames=121
duration≈5s
```

num_frames 必须允许通过配置修改，不能散落硬编码。

## 7. 图片上传

实现批量图片上传：

- 支持 PNG / JPG / JPEG / WEBP。
- 支持一次拖入多张。
- 单张图片大小限制做成配置。
- 保存到：
  `/data/poem-video-studio/uploads/{batch_id}/`
- 文件名必须避免覆盖。
- 前端支持调整图片顺序。
- 支持标记 cover。
- 支持将每张图片绑定到 scene_key。

推荐按文件名辅助识别：

```text
cover.png
01.png
02.png
03.png
04.png
```

但用户必须能够手工重新绑定，不能完全依赖文件名。

## 10. 校验规则

必须阻止以下情况进入下一步：

- 批量文本版本头错误
- scene 重复
- scene 缺 Prompt
- scene 缺 speech
- scene 没有绑定图片
- 图片数量与场景数量不匹配且未完成手工绑定
- width / height / fps / num_frames 非法
- 空批次

## 13. 验收标准

使用《宿建德江》作为测试数据：

- 1 张封面图 + 4 张诗句图。
- 一次粘贴完整批量文本。
- “解析任务”后得到 5 个场景。
- 每个场景正确显示 speech 和 prompt。
- 5 张图均能正确绑定。
- 点击“创建批次”后数据库生成 1 个 Batch + 5 个 VideoTask。
- 刷新页面后数据仍然存在。
- 不依赖 ComfyUI 即可独立完成本任务验收。
